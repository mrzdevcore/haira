Compiler Pipeline

6-stage pipeline: .haira source code to standalone binary with embedded runtime, UI, and tree-shaken stdlib.

ARP — Agentic Rendering Protocol

Wayland-inspired display protocol for agents. Typed components, capability negotiation, double-buffered rendering, bidirectional input.

Generative UI — Component Model

Agents emit typed components. The renderer maps each to a native UI element. Fallback chains ensure graceful degradation.

ARP vs AG-UI — Architectural Comparison

AG-UI is an event bus. ARP is a display server. Different mental models, different capabilities.
