\chapter{Overview}
\label{ch:overview}

\haira{} is a statically-typed, compiled programming language for building AI agents and workflows. It combines the simplicity of Go, the safety of Rust, and purpose-built primitives for agentic orchestration --- agents, tools, workflows, and providers are first-class language constructs, not library imports.

\haira{} compiles to native binaries via Cranelift, with no runtime dependencies beyond the standard library.

\section{Hello, Agent}

\begin{lstlisting}
import "io"

provider local {
    backend: "ollama"
    host: "localhost:11434"
    model: "llama3:8b"
}

agent Greeter {
    provider: local
    system: "You are a friendly greeter. Keep it short."
}

fn main() {
    reply, err = Greeter.ask("Say hello to the world!")
    if err != nil {
        io.println("Error: " + err.message)
        return
    }
    io.println(reply)
}
\end{lstlisting}

To compile and run:

\begin{lstlisting}[language=bash,numbers=none]
$ haira build hello.haira
$ ./hello
Hello, world! Great to meet you!
\end{lstlisting}

\section{Language Characteristics}

\subsection{Four Agentic Primitives}

\haira{} adds four keywords to a general-purpose language:

\begin{itemize}
    \item \keyword{provider} --- Configure LLM backends (Anthropic, OpenAI, Ollama, local models)
    \item \keyword{tool} --- Typed functions with LLM-visible descriptions; the compiler auto-generates JSON schemas
    \item \keyword{agent} --- LLM-powered entities with a model, system prompt, tools, and optional memory
    \item \keyword{workflow} --- Composable pipelines with triggers, typed I/O, and native concurrency
\end{itemize}

\subsection{Explicit Imports}

All dependencies are explicitly declared at the top of each file:

\begin{lstlisting}
import "io"
import "json"
import "tools/http"
import "tools/postgres"
\end{lstlisting}

\subsection{Go-Style Error Handling}

Functions that can fail return a tuple of result and error:

\begin{lstlisting}
import "io"
import "fs"

fn main() {
    content, err = fs.read_file("config.json")
    if err != nil {
        io.println("Error: " + err.message)
        return
    }
    io.println(content)
}
\end{lstlisting}

\subsection{Agents and Tools}

Agents are declared with a model, system prompt, and tools. Tools are typed functions with descriptions:

\begin{lstlisting}
import "io"
import "tools/http"

provider anthropic {
    api_key: env("ANTHROPIC_API_KEY")
    model: "claude-sonnet-4-20250514"
}

tool search(query: string) -> [Result] {
    """Search the web for information"""

    resp, err = http.get("https://api.search.com?q={query}")
    if err != nil { return [], err }
    return json.decode(resp.body, [Result])
}

agent Researcher {
    provider: anthropic
    system: "You are a thorough researcher. Always cite sources."
    tools: [search]
    temperature: 0.2
}

fn main() {
    answer, err = Researcher.ask("What is quantum computing?")
    if err != nil {
        io.println("Error: " + err.message)
        return
    }
    io.println(answer)
}
\end{lstlisting}

\subsection{Workflows with Triggers}

Workflows are functions with triggers. They can be exposed as webhooks, scheduled with cron, or triggered by events:

\begin{lstlisting}
@webhook("/summarize")
workflow Summarizer(url: string) -> Summary {
    content = fetch_page(url)
    summary = Researcher.ask("Summarize this: {content}")
    return Summary{ text: summary, word_count: summary.len() }
}

fn main() {
    server = http.Server([Summarizer])
    io.println("Running on :8080")
    server.listen(8080)
}
\end{lstlisting}

\subsection{Streaming and Conversations}

Agents support streaming responses and session-based memory for chatbot use cases:

\begin{lstlisting}
agent Assistant {
    provider: anthropic
    system: "You are a helpful assistant."
    memory: conversation(max_turns: 50)
}

@websocket("/chat")
workflow Chat(message: string, session_id: string) -> stream<string> {
    return Assistant.stream(message, session: session_id)
}
\end{lstlisting}

\section{Type System}

\haira{} uses structural typing with type inference for local variables:

\begin{lstlisting}
// Type inferred as int
count = 42

// Explicit type annotation
name: string = "Haira"

// Struct definition
struct Point {
    x: float
    y: float
}

// Option type (nullable)
maybe_value: int? = nil

// Arrays and maps
numbers: []int = [1, 2, 3]
scores: [string:int] = ["alice": 100, "bob": 95]
\end{lstlisting}

\section{Functions}

Functions are declared with \keyword{fn}:

\begin{lstlisting}
fn add(a: int, b: int) -> int {
    return a + b
}

fn divide(a: int, b: int) -> (int, Error?) {
    if b == 0 {
        return 0, Error{message: "division by zero"}
    }
    return a / b, nil
}
\end{lstlisting}

\section{Concurrency}

\haira{} provides Go-style concurrency with \keyword{spawn} and channels:

\begin{lstlisting}
import "io"

fn main() {
    ch = chan<int>(10)

    spawn {
        for i in 0..5 {
            ch <- i
        }
        close(ch)
    }

    for value in ch {
        io.println(value)
    }
}
\end{lstlisting}

Inside workflows, \keyword{spawn} blocks run steps in parallel:

\begin{lstlisting}
@manual
workflow ParallelReview(article: Article) -> [Review] {
    reviews = spawn {
        Reviewer.run(ReviewRequest{ article: article, focus: "accuracy" })
        Reviewer.run(ReviewRequest{ article: article, focus: "clarity" })
        Reviewer.run(ReviewRequest{ article: article, focus: "style" })
    }
    return reviews
}
\end{lstlisting}

\section{Pipe Operator}

The pipe operator \code{|>} enables functional composition:

\begin{lstlisting}
import "io"
import "string"
import "array"

fn main() {
    result = "  hello, world  "
        |> string.trim
        |> string.to_upper
        |> string.split(", ")
        |> array.first

    io.println(result)  // "HELLO"
}
\end{lstlisting}

\section{A Complete Example}

A multi-agent workflow that researches a topic, writes an article, and reviews it:

\begin{lstlisting}
import "io"

provider anthropic {
    api_key: env("ANTHROPIC_API_KEY")
    model: "claude-sonnet-4-20250514"
}

struct Article { title: string, body: string, sources: [string] }
struct Review { aspect: string, score: float, notes: string }

tool search(query: string) -> [string] {
    """Search the web and return relevant URLs"""

    resp, err = http.get("https://api.search.com?q={query}")
    if err != nil { return [], err }
    return json.decode(resp.body, [string])
}

agent Researcher {
    provider: anthropic
    system: "You are a thorough researcher."
    tools: [search]
    temperature: 0.2
}

agent Writer {
    provider: anthropic
    system: "You are a clear technical writer."
    temperature: 0.7
}

agent Reviewer {
    provider: anthropic
    system: "You are a critical but constructive editor."
    temperature: 0.1
}

@manual
workflow WriteArticle(topic: string) -> Article {
    research = Researcher.ask("Research this topic thoroughly: {topic}")

    draft: Article, err = Writer.run(
        { research: research, topic: topic }
    ) -> Article
    if err != nil { return Article{}, err }

    reviews = spawn {
        Reviewer.ask("Review for accuracy: {draft.body}")
        Reviewer.ask("Review for clarity: {draft.body}")
    }

    io.println("Reviews complete: {reviews.len()}")
    return draft
}

fn main() {
    article, err = WriteArticle("The future of agentic programming")
    if err != nil {
        io.println("Failed: " + err.message)
        return
    }
    io.println(article.title)
    io.println(article.body)
}
\end{lstlisting}
